# Обзор проекта для защиты

Приложение хранит обращения в техподдержку так, чтобы их нельзя было потерять: каждой заявке назначены категория, приоритет, срок и контролируемый статус. Оно показывает просрочку, журнал переходов и статистику руководителю.

Java выбрана как основной промышленный язык backend и используется для API, правил и БД. Kotlin добавлен не формально: на нём работает сервис отчётности и DTO результата. Spring Boot быстро собирает web-сервер, валидацию, JPA, health checks и документацию в одно приложение.

Архитектура слоистая. Controller переводит HTTP в вызов приложения. DTO описывает внешний контракт. Service применяет бизнес-правила и транзакции. Repository работает с PostgreSQL через JPA/Hibernate. Mapper не даёт JPA-сущностям попасть наружу. Flyway создаёт схему. Для отчёта Java controller вызывает Kotlin service, тот обращается к Java data provider и агрегирует одну выборку.

Ключевая идея защиты целостности: статус и строка истории сохраняются в одной транзакции, а поле `version` обнаруживает одновременное изменение. Завершённые состояния терминальны. `closedAt` существует только у RESOLVED; отмена не считается решением.
